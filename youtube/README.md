Chapters

What each one does
Fair Split: Split costs with housemates or a trip group. No sign-up, no daily limits and no server: the whole book travels inside a link you send to the group chat.

Citation Check: Paste a reference list in any style and every reference is checked against Crossref and OpenAlex. It catches papers that don’t exist, a real DOI attached to the wrong paper, and wrong years. Court citations link to CourtListener.

Hidden Text Finder: Drop in CVs (PDF or Word) and see the white, microscopic and off-page text written for AI screeners, painted back where it sits. Files are read in your browser and never uploaded.

QR Check: Scan or paste a QR code and see whether a link service sits between the code and your page, holding the switch. Then make a direct code that never expires.

Memories Fixer: Puts the dates, places and captions back on your Snapchat Memories download, in the local time where each one was taken, ready for Google Photos. Nothing is uploaded.

The five Android apps are next.

Every demo is recorded from the real app. Narration is an open-source synthetic voice (Kokoro).

**In YouTube Studio:**
1. Upload the video, paste the title and description, and set the thumbnail.
2. Subtitles: Add language, English, then Upload file, "With timing", and choose the .srt file.
3. The chapters come from the timestamps in the description; they start at 0:00, so YouTube picks them up.
4. "Altered or synthetic content": the narration is a synthetic voice, but it isn't anyone real and nothing shown is altered, so YouTube's rules don't ask for the label. Tick it anyway if you'd rather.
